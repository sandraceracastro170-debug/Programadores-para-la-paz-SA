El login permite identificar a un usuario antes de acceder a la plataforma. Algunas rutas deben estar protegidas porque contienen información privada o funciones importantes. Solo los usuarios autorizados deben acceder a ellas. No se deben mostrar públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles. Esto ayuda a proteger la privacidad y la seguridad de la comunidad.
