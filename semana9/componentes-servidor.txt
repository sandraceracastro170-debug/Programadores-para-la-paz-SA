Sistema operativo:
Es el software principal del computador o servidor. Administra los recursos del sistema y permite ejecutar aplicaciones.

Node.js:
Es un entorno que permite ejecutar código JavaScript fuera del navegador y crear aplicaciones de servidor.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor y las rutas que responderán a las solicitudes.

Puerto:
Es un punto de comunicación utilizado por el servidor para recibir conexiones. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre la actividad, eventos y errores del servidor para facilitar el monitoreo y la solución de problemas.
